# Third-party components and licence plan

**Not legal advice. Items marked LEGAL CHECK need a lawyer before a public release.**

## Shipped in the Lavora installer today
| Component | Licence | How shipped | Notes |
|---|---|---|---|
| Python runtime | PSF | frozen into the app folder | text in `THIRD_PARTY_NOTICES.txt` |
| Qt 6 / PySide6 / shiboken6 | LGPL-3.0 | separate DLLs in `_internal\PySide6` (replaceable) | LGPL source offer: https://code.qt.io ; keep Qt as dynamic libraries, do not static-link |
| cryptography (+ cffi, pycparser) | Apache-2.0 OR BSD-3 (cryptography), MIT (cffi), BSD (pycparser) | frozen | `cryptography` bundles OpenSSL (Apache-2.0) |

Lavora's own code: MIT (`LICENSE.txt`).

## Planned external tools (NOT bundled yet - separate executables only)
Rule: GPL/AGPL tools are run as **separate processes**, never imported or linked, and ship with their licence text and a
written offer (or link) for the corresponding source of the exact version shipped.

| Tool | Licence (verify per release) | Used for | Phase |
|---|---|---|---|
| smartmontools (`smartctl`) | GPL-2.0-or-later | SMART health (`lavora-cli smart`; parser already tested) | 2 |
| GNU ddrescue | GPL-3.0-or-later | optional alternative imager in Rescue | 3 |
| The Sleuth Kit | mixed (IPL-1.0, CPL-1.0, GPL-2.0) | optional cross-check | 3 |
| TestDisk / PhotoRec | GPL-2.0-or-later | optional cross-check / fallback carving | 3 |
| ntfs-3g | GPL-2.0 (driver), LGPL (lib) | Rescue: mount NTFS | 3 |
| ClamAV | GPL-2.0 (+ bundled third-party) | offline malware scan in Rescue | 3 |
| GRUB tools, efibootmgr, cryptsetup, e2fsprogs | GPL | Rescue only (live ISO) | 3 |
| Debian live-build base | various (Debian packages) | Rescue ISO; the ISO is a *distribution* of GPL software: source offer for every package | 3 |

**LEGAL CHECK**
1. Distributing the Rescue ISO means distributing GPL packages: keep Debian's source listings or host source for each.
2. WinPE/ADK terms (see `docs/windows-boot-repair.md`): do not redistribute a ready-made WinPE image.
3. "Lavora" trademark clearance is pending; the name lives only in `lavora/brand.py`.
4. ClamAV definitions: check the update-mirror terms before bundling signatures.
5. Icon and wizard artwork are **placeholders** generated by `tools/make_assets.py`.
